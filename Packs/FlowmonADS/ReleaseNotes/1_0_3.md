#### Integrations

##### Flowmon ADS

- Improved incident severity mapping: priority is now resolved from the maximum value across all assigned perspectives (fallback to top-level event priority). This correctly classifies events that carry `priority: 0` at the top level but have a non-zero priority within their perspectives.
- Added `priority: 0` → Unknown severity mapping for events that are truly unclassified.
- Populated XSIAM alert **Description** field with the event's `detail` text.
- Set alert **category** to `Network Security` so that alerts appear in the Security alert domain in XSIAM.
