#### Integrations

##### Flowmon ADS

- Added **Source Hostname** field (`source.resolved`) to incident custom fields and context output.
- Added **MITRE ATT&CK Techniques** field from event `techniques` array; automatically populates the built-in `mitreattcktechnique` XSIAM field when technique IDs are present.
- Stripped internal Flowmon noise fields (`appmapSummary`, `methodInstance`, `_collector_name`) from the raw event stored in XSIAM to reduce clutter in the Evidence table.

#### Layouts

##### Flowmon ADS Event

- Added custom incident layout with **Network Context** section (Source IP, hostname, country, target IPs, NF source) and **Detection Details** section (event ID, type, detection model, priority, interest, perspectives), plus a dedicated **MITRE ATT&CK** tab.
